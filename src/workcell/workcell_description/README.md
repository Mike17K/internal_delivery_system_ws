# workcell_description

## Quick dev-workspace setup

```bash
export GZ_SIM_RESOURCE_PATH=$PWD/models:$GZ_SIM_RESOURCE_PATH
```

## Office floor world

`worlds/office_world.sdf` is a full office floor: a corridor flanked by
individual offices, a meeting room, a break room, and a lobby, built out
of reusable models under `models/`:

- `office_floor` — the whole building, generated by
  `scripts/generate_office_floor.py`. Re-run that script after tweaking any
  layout constant at the top of the file (office count, room size, corridor
  width, wall thickness, door width, ...) to regenerate `models/office_floor/model.sdf`.
- `office_desk`, `office_chair`, `office_cabinet`, `potted_plant`,
  `ceiling_light` — reusable furniture/fixtures placed throughout every
  room.
- `reception_desk`, `meeting_table`, `break_counter` — one-off furniture
  for the lobby, meeting room, and break room.

Standalone launch:

```bash
ros2 launch workcell_description office_world.launch.py
```

Or, from `workcell_bringup`, point the existing bringup launch at this
world:

```bash
ros2 launch workcell_bringup workcell.launch.py sim_gazebo:=true \
  world:=$(ros2 pkg prefix workcell_description)/share/workcell_description/worlds/office_world.sdf
```

`office_world.sdf` declares its own physics tuning (ODE quick solver) and
the required Gazebo Sim system plugins (Physics, SceneBroadcaster,
Sensors, UserCommands, Contact) plus a scene/ambient/shadow configuration,
so it does not rely on gz-sim's implicit default plugin set.
